How It Works

          

            

              
01

              

                
Text Preprocessing

                
HTML tags and URLs are stripped. Title and body are concatenated with a [SEP] token before tokenization.

              

            

            

              
02

              

                
DistilBERT Encoding

                
The article is tokenized to max 512 tokens and encoded by a DistilBERT encoder (66M parameters).

              

            

            

              
03

              

                
Classification Head

                
A linear classification head over the [CLS] token outputs logits → softmax probabilities for REAL/FAKE.

              

            

            

              
04

              

                
REST API Response

                
Results are returned in <100ms via a Dockerized FastAPI endpoint with CORS-enabled JSON responses.
